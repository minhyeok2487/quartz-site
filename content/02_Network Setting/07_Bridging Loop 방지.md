> 스위치 네트워크에서 물리적 루프(고리)가 생겨서 프레임이 무한 순환하는 현상

만약 정상적인 네트워크 라면
```
[PC]---[Switch1]---[Switch2]---[Server]
         ↓
      한 방향으로만 전달
```

### 루프 발생
```
	 [Switch1]
       /            \
      /               \
  [Switch2]--[Switch3]
    ↑                  ↓
    └────┘
   프레임이 무한 순환! 🔄
```

### 발생 과정
1. 브로드캐스트 전송
```
PC가 브로드캐스트 전송 (ARP 등)
→ Switch1이 모든 포트로 전달
→ Switch2와 Switch3로 전송
```

2. 무한 순환 시작
```
Switch1 → Switch2 → Switch3 → Switch1 → ...
         ↓         ↓         ↓
    같은 프레임이 계속 복사되어 증폭!
```

3. 브로드캐스트 스톰 발생
```
1개 프레임 → 2개 → 4개 → 8개 → 16개 → ...
```
