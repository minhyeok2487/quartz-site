# 이전 장 요약

이전 장에서는 **네트워크 유형**을 크기와 범위에 따라 분류했습니다:
- **PAN**: 개인 영역 네트워크 (블루투스, 10m)
- **LAN**: 지역 네트워크 (사무실, 집, 1km)
- **WLAN**: 무선 LAN (Wi-Fi, 100m)
- **MAN**: 도시권 네트워크 (전용선, 50km)
- **WAN**: 광역 네트워크 (인터넷, 무제한)

이제 **특수 목적 네트워크**와 **네트워크를 구성하는 하드웨어**에 대해 알아봅시다.

# 7. 기타 네트워크 유형

지금까지 PAN, LAN, WLAN, MAN, WAN을 살펴봤습니다. 하지만 네트워크 세상에는 특수한 목적의 네트워크들도 있습니다.

## CAN (Campus Area Network)

**정의**: 여러 건물로 이루어진 캠퍼스를 연결하는 네트워크입니다. LAN보다 크고 MAN보다 작습니다.

**예시**:
- 대학교 캠퍼스 (여러 건물)
- 대기업 사옥 단지 (삼성 수원 사업장처럼 여러 건물)
- 병원 단지 (본관, 별관, 연구동 등)

**특징**:
- 범위: 1-5km
- 속도: 1-10Gbps (광케이블)
- 소유: 한 조직이 소유하고 관리
- 기술: 이더넷, 광케이블

**LAN vs CAN vs MAN**:
- LAN: 한 건물 안
- CAN: 여러 건물, 하지만 한 조직 소유지
- MAN: 도시 곳곳, 통신사 인프라 이용

## SAN (Storage Area Network)

**정의**: 저장 장치들을 연결하는 **특수 목적 네트워크**입니다.

일반적인 네트워크는 컴퓨터와 컴퓨터를 연결하지만, SAN은 **서버와 스토리지**를 연결합니다.

### 왜 SAN이 필요할까?

대기업의 데이터센터를 생각해 보세요. 수백 대의 서버가 있고, 수 페타바이트(1PB = 1,000TB)의 데이터를 저장해야 합니다.

각 서버마다 하드디스크를 달면:
- 비효율적 (하드디스크가 놀고 있는 서버도 있음)
- 관리 어려움 (서버마다 백업해야 함)
- 확장 어려움 (서버마다 개별적으로 업그레이드)

그래서 **스토리지를 분리**합니다. 서버들은 계산만 하고, 데이터는 모두 SAN에 저장합니다.

### SAN의 구조

```
[서버들] ←→ [SAN 스위치] ←→ [스토리지 어레이]
                                (수백 개의 하드디스크)
```

### 기술

- **파이버 채널(Fibre Channel)**: 전용 프로토콜, 매우 빠름 (16-128Gbps)
- **iSCSI**: 일반 이더넷으로 SCSI 프로토콜 전송, 저렴함
- **NVMe over Fabrics**: 최신 기술, SSD를 네트워크로 연결

### 예시

넷플릭스를 생각해 보세요. 전 세계 수억 명이 동시에 영상을 봅니다. 이 모든 영상이 어디 저장되어 있을까요? SAN입니다.

수천 대의 서버가 SAN에 연결되어, 필요한 영상을 빠르게 읽어서 사용자들에게 스트리밍합니다.

## VPN (Virtual Private Network)

**정의**: 공개 네트워크(인터넷) 위에 **가상의 사설 네트워크**를 만드는 기술입니다.

### VPN의 원리

VPN은 **터널링**을 씁니다. 여러분의 데이터를 암호화해서 캡슐에 넣고, 그 캡슐을 인터넷으로 보냅니다. 중간에 누가 가로채도 암호화되어 있어서 못 읽습니다.

```
[여러분 컴퓨터] → [암호화] → [인터넷] → [복호화] → [회사 네트워크]
```

### VPN의 종류

#### 원격 접속 VPN (Remote Access VPN)

집에서 회사 네트워크에 접속할 때 씁니다.

**시나리오**: 여러분이 재택근무를 합니다. 회사 서버에 있는 파일이 필요한데, 보안상 외부에서 직접 접속할 수 없습니다.

**해결**: VPN 클라이언트를 실행합니다. 회사 VPN 서버에 연결하면, 이제 여러분 컴퓨터는 회사 네트워크의 일부가 됩니다. 회사 파일 서버, 사내 웹사이트 등 모든 자원에 접근할 수 있습니다.

**기술**:
- **IPsec**: 표준 프로토콜, 안전하지만 설정 복잡
- **SSL VPN**: 웹브라우저로 접속, 편리함
- **OpenVPN**: 오픈소스, 유연함
- **WireGuard**: 최신 기술, 빠르고 간단함

#### 사이트 간 VPN (Site-to-Site VPN)

두 사무실을 연결할 때 씁니다.

**시나리오**: 회사가 서울과 부산에 사무실이 있습니다. 전용선(MAN)은 너무 비쌉니다. 대신 인터넷에 VPN을 만들어서 연결합니다.

각 사무실에 VPN 라우터를 설치하고, 두 라우터가 인터넷을 통해 VPN 터널을 만듭니다. 이제 서울과 부산 직원들은 마치 같은 사무실에 있는 것처럼 네트워크를 씁니다.

**장점**:
- 전용선보다 훨씬 저렴
- 인터넷만 있으면 어디든 연결 가능

**단점**:
- 인터넷 품질에 의존
- 전용선보다 느리고 불안정

### VPN의 보안

VPN은 보안을 위해 여러 기술을 씁니다:

1. **암호화**: AES-256 같은 강력한 암호로 데이터 보호
2. **인증**: 사용자와 서버가 서로 신원 확인
3. **무결성**: 데이터가 중간에 변조되지 않았는지 확인

### 개인용 VPN

요즘은 개인들도 VPN을 많이 씁니다:

- **공개 Wi-Fi 보안**: 카페에서 Wi-Fi 쓸 때 VPN으로 보호
- **개인정보 보호**: IP 주소 숨기기
- **지역 제한 우회**: 다른 나라 콘텐츠 접근 (넷플릭스 등)

하지만 조심해야 합니다. 무료 VPN은 오히려 여러분 데이터를 수집할 수 있습니다. 믿을 수 있는 VPN 서비스를 쓰세요.


# 8. 네트워크 구성 요소 개요

네트워크를 구성하는 하드웨어 장비들이 있습니다. 각 장비는 특정한 역할을 하며, OSI 7계층 모델의 다른 계층에서 작동합니다.

## 주요 네트워크 장비

다음은 네트워크를 구성하는 핵심 장비들입니다:

**물리 계층 (Layer 1)**:
- **NIC (Network Interface Card)**: 컴퓨터를 네트워크에 연결하는 하드웨어
- **Hub**: 신호를 모든 포트로 전달 (현재는 거의 사용 안 함)
- **Modem**: 디지털 신호와 아날로그 신호를 변환

**데이터 링크 계층 (Layer 2)**:
- **Switch**: MAC 주소를 이용해 지능적으로 데이터 전달
- **Access Point (AP)**: 유선 네트워크와 무선 기기를 연결

**네트워크 계층 (Layer 3)**:
- **Router**: 서로 다른 네트워크를 연결하고 경로를 결정
- **Layer 3 Switch**: 스위칭과 라우팅 기능을 모두 가진 장비

**상위 계층**:
- **Firewall**: 네트워크 보안을 담당하는 장비

## OSI 계층별 장비 및 케이블 분류

| OSI 계층 | 장비 | 케이블 |
|----------|------|--------|
| **7계층 (Application)** | - | - |
| **6계층 (Presentation)** | - | - |
| **5계층 (Session)** | - | - |
| **4계층 (Transport)** | Firewall (NGFW) | - |
| **3계층 (Network)** | Router, L3 Switch | - |
| **2계층 (Data Link)** | Switch, Bridge, AP | - |
| **1계층 (Physical)** | Hub, Repeater, NIC, Modem | UTP, 광케이블 |

## 케이블 종류

**UTP (Unshielded Twisted Pair)**:
- 일반 이더넷 케이블
- Cat5e, Cat6, Cat6A 등
- 최대 거리: 100m
- 속도: 100Mbps - 10Gbps

**광케이블 (Fiber Optic)**:
- 빛으로 데이터 전송
- 싱글모드(장거리), 멀티모드(단거리)
- 최대 거리: 수십 km
- 속도: 1Gbps - 100Gbps 이상

## 더 자세히 알고 싶다면

각 장비의 **상세한 동작 원리, 종류, 선택 기준, 실전 활용법**은 **06_계층별 장비와 케이블.md**에서 심도 있게 다룹니다.

6장에서는 다음 내용을 배우게 됩니다:
- 각 장비의 구체적인 동작 원리와 프로토콜
- 장비 선택 시 고려해야 할 기술적 사양
- 실무에서의 장비 배치 전략
- 케이블 선택과 포설 기준
- Collision Domain과 Broadcast Domain
- 실제 네트워크 설계 시나리오


# 9. 실전 시나리오 - 종합해보기

이론으로 배운 것들을 실제 상황에 어떻게 적용하는지 봅시다.

## 시나리오 1: 스타트업의 사무실 네트워크 구축

### 상황

여러분이 50명 규모의 IT 스타트업 CTO입니다. 강남에 새 사무실을 얻었습니다. 네트워크를 처음부터 구축해야 합니다.

**요구사항**:
- 직원 50명 (개발자 30, 디자이너 10, 경영지원 10)
- 서버룸 별도 구축
- 회의실 3개
- Wi-Fi 필수
- 보안 중요
- 예산: 2000만원

### 설계

#### 1단계: 인터넷 회선

- **기업용 광랜 1Gbps** 계약 (월 30만원)
- 왜? 집 인터넷으로는 50명이 못 씀. 고정 IP 필요.

#### 2단계: 장비 선정

**라우터/방화벽**:
- FortiGate 60F (150만원)
- 라우팅 + 방화벽 + VPN 기능 통합

**코어 스위치**:
- 24포트 기가비트 매니지드 스위치 (80만원)
- VLAN 설정 가능해야 함

**액세스 스위치**:
- 8포트 스위치 6대 (각 10만원, 총 60만원)
- 책상 그룹마다 1대

**무선 AP**:
- 업무용 AP 5대 (각 30만원, 총 150만원)
- PoE 지원, Controller로 관리

**PoE 스위치**:
- 8포트 PoE 스위치 (50만원)
- AP에 전원 공급

**서버 장비**:
- 파일 서버 NAS (300만원)
- 백업 NAS (200만원)

**UPS (무정전 전원장치)**:
- 핵심 장비용 UPS 2대 (총 100만원)

**케이블 및 설치**:
- Cat6 케이블, 패치 패널 등 (200만원)

**총액**: 약 1,290만원 (예산 내)

#### 3단계: 네트워크 구조

```
[인터넷]
   ↓
[FortiGate 방화벽/라우터]
   ↓
[코어 스위치]
   ├─ VLAN 10: 개발팀 네트워크
   ├─ VLAN 20: 디자인팀 네트워크
   ├─ VLAN 30: 경영지원팀 네트워크
   ├─ VLAN 40: 서버 네트워크
   ├─ VLAN 50: 손님 Wi-Fi
   └─ VLAN 60: 직원 Wi-Fi
```

#### 4단계: IP 주소 계획

- **VLAN 10 (개발)**: 192.168.10.0/24
- **VLAN 20 (디자인)**: 192.168.20.0/24
- **VLAN 30 (경영지원)**: 192.168.30.0/24
- **VLAN 40 (서버)**: 192.168.40.0/24
- **VLAN 50 (손님 Wi-Fi)**: 192.168.50.0/24
- **VLAN 60 (직원 Wi-Fi)**: 192.168.60.0/24

#### 5단계: 보안 설정

**방화벽 규칙**:
1. 모든 내부 → 인터넷: 허용
2. 손님 Wi-Fi → 내부 네트워크: 차단
3. 손님 Wi-Fi → 인터넷만: 허용
4. 개발팀 → 서버: 허용
5. 외부 → 웹서버(만약 있다면): 허용
6. 나머지: 차단

**Wi-Fi 보안**:
- WPA3-Enterprise (직원용)
- WPA2-Personal (손님용, 매일 비밀번호 변경)

**기타**:
- 모든 장비 펌웨어 최신 유지
- 관리자 비밀번호 강력하게
- 원격 관리는 VPN 통해서만

#### 6단계: 백업 및 재해 복구

- 파일 서버 → 백업 NAS (매일 자동 백업)
- 중요 데이터 → 클라우드 백업 (주 1회)
- 네트워크 설정 백업 (월 1회)

### 결과

이렇게 구축하면:
- **빠름**: 기가비트 속도
- **안정적**: 이중화된 스위치, UPS로 정전 대비
- **안전함**: VLAN 분리, 방화벽, 강력한 Wi-Fi 암호화
- **확장 가능**: 직원이 늘어나도 스위치/AP만 추가하면 됨
- **관리 용이**: VLAN으로 논리적 분리, 중앙 관리

## 시나리오 2: 재택근무 직원의 VPN 연결

### 상황

여러분은 회사 직원입니다. 코로나로 인해 재택근무를 하게 되었습니다. 회사 파일 서버에 접속해야 하는데, 보안상 외부에서 직접 접속은 불가능합니다.

### 해결: VPN

#### 1단계: VPN 클라이언트 설치

IT팀이 제공한 **FortiClient VPN**을 설치합니다.

#### 2단계: VPN 설정

- **서버 주소**: vpn.company.com
- **사용자 이름**: 여러분 회사 ID
- **비밀번호**: 회사 비밀번호
- **2단계 인증**: 스마트폰 OTP

#### 3단계: 연결

1. FortiClient 실행
2. 연결 버튼 클릭
3. 2단계 인증 코드 입력
4. 연결 완료

#### 4단계: 작업

이제 여러분 컴퓨터는 마치 회사 사무실에 있는 것처럼 작동합니다.

- 파일 서버: `\\fileserver\share` 접속 가능
- 사내 웹사이트: `http://intranet.company.local` 접속 가능
- 개발 서버: SSH로 접속 가능

#### 보안 주의사항

- **공개 Wi-Fi 주의**: 카페 Wi-Fi는 안전하지 않음. VPN으로 암호화되긴 하지만, 가능하면 집 인터넷 쓰기
- **화면 잠금**: 자리 비울 때 화면 잠금
- **바이러스 백신**: 항상 최신 유지
- **의심스러운 이메일**: 클릭하지 말기

## 시나리오 3: 카페의 Wi-Fi 네트워크 문제 해결

### 상황

동네 카페 사장님이 고민이 있습니다. 손님들이 Wi-Fi가 느리다고 불평합니다. 특히 저녁에는 더 심합니다.

**현재 구성**:
- 가정용 공유기 1대 (5만원짜리)
- 카페 구석에 위치
- SSID: Cafe_Free
- 비밀번호: 없음 (개방)

**문제**:
- 카페 반대편은 신호가 약함
- 동시 접속자 많으면 느려짐
- 가끔 다운됨

### 해결

#### 진단

1. **공유기 위치**: 구석이라 전체 커버 안 됨
2. **장비 성능**: 가정용 공유기는 동시 접속 10-20명이 한계
3. **보안**: 개방 네트워크라 누구나 접속 가능
4. **간섭**: 주변 카페들도 같은 채널 사용

#### 개선 방안

**단계 1: 장비 업그레이드**

- 가정용 공유기 제거
- **업무용 AP 2대** 설치 (각 30만원)
  - 천장에 설치 (전체 커버)
  - PoE 지원
  - 동시 접속 50-100명 가능

**단계 2: 네트워크 분리**

```
[인터넷 회선]
   ↓
[공유기/라우터]
   ↓
[스위치]
   ├─ AP 1 (홀 앞쪽)
   ├─ AP 2 (홀 뒤쪽)
   └─ POS + 사무용 PC
```

**SSID 분리**:
- **Cafe_Guest**: 손님용, 대역폭 제한 (1인당 5Mbps)
- **Cafe_Private**: 직원용, POS와 사무 연결

**단계 3: 보안 강화**

- WPA2-Personal 암호 설정
- 비밀번호는 매주 변경, 벽에 게시
- 게스트 격리 (손님들끼리 서로 못 봄)

**단계 4: 채널 최적화**

- Wi-Fi 분석 앱으로 주변 채널 확인
- 가장 적게 쓰는 채널 선택
- 2.4GHz: 1, 6, 11 중 하나
- 5GHz: 자동 선택

**단계 5: QoS 설정**

- POS 우선순위 높임 (결제 시스템은 항상 빨라야 함)
- 토렌트, P2P 차단
- 스트리밍은 중간 우선순위

#### 비용

- 업무용 AP 2대: 60만원
- PoE 스위치: 15만원
- 케이블 및 설치: 10만원
- **총**: 85만원

#### 결과

- **빠름**: 동시 접속 50명도 문제없음
- **안정적**: 더 이상 다운 안 됨
- **전체 커버**: 카페 어디서나 신호 좋음
- **보안**: 암호로 보호됨
- **관리 용이**: POS는 영향 안 받음

손님 만족도 상승, 카페 매출도 증가했습니다.

## 시나리오 4: 가정 네트워크 최적화

### 상황

여러분 집에 가족 4명이 살고, 각자 여러 기기를 씁니다:

- 엄마: 스마트폰, 노트북
- 아빠: 스마트폰, 데스크톱
- 자녀 1: 스마트폰, 게임 콘솔, 노트북
- 자녀 2: 스마트폰, 태블릿

총 11개 기기입니다. 플러스 스마트 TV, IoT 기기들까지 하면 15개가 넘습니다.

**문제**:
- 저녁에 넷플릭스 보면 게임 렉 걸림
- Wi-Fi가 안방까지 안 닿음
- 가끔 인터넷이 끊김

### 해결

#### 진단

1. **대역폭**: 인터넷 100Mbps인데, 넷플릭스 4K가 25Mbps 씀
2. **커버리지**: 공유기가 거실에 있어서 안방은 약함
3. **공유기 과부하**: 5년 된 구형 공유기, 펌웨어 안 올림

#### 개선 방안

**옵션 1: 간단한 해결 (예산 30만원)**

- **새 공유기** 구매 (Wi-Fi 6 지원, 15만원)
  - 속도 빠름
  - 동시 접속 많아도 안정적
- **Wi-Fi 확장기** 1대 (10만원)
  - 안방까지 커버

**옵션 2: 완벽한 해결 (예산 50만원)**

- **메시 Wi-Fi** 시스템 (3팩, 45만원)
  - Google Wifi, eero, 또는 TP-Link Deco
  - 거실, 복도, 안방에 각 1대
  - 집 전체 균일한 커버리지

**네트워크 설정**:

1. **QoS 설정**:
   - 게임: 높은 우선순위
   - 넷플릭스: 중간 우선순위
   - 파일 다운로드: 낮은 우선순위

2. **밴드 분리**:
   - 2.4GHz: IoT 기기 (스마트 전구, 에어컨 등)
   - 5GHz: 노트북, 스마트폰, 게임 (빠른 기기)

3. **주기적 재부팅**:
   - 공유기를 1-2주에 한 번 재부팅
   - 또는 새벽 4시에 자동 재부팅 설정

#### 결과

- 게임 렉 없어짐
- 넷플릭스 4K도 끊김 없음
- 집 어디서나 Wi-Fi 잘 잡힘
- 가족 모두 만족

# 10. 마무리 - 네트워크의 큰 그림

여기까지 배운 내용을 정리해 봅시다.

## 네트워크 유형 요약

| 유형 | 범위 | 속도 | 예시 | 소유 |
|------|------|------|------|------|
| **PAN** | 10m | 2-50Mbps | 블루투스 이어폰 | 개인 |
| **LAN** | 1km | 1-10Gbps | 사무실, 집 | 조직/개인 |
| **WLAN** | 100m | 100Mbps-1Gbps | Wi-Fi | 조직/개인 |
| **CAN** | 5km | 1-10Gbps | 대학 캠퍼스 | 조직 |
| **MAN** | 50km | 100Mbps-10Gbps | 도시 내 지점들 | 통신사/조직 |
| **WAN** | 무제한 | 다양 | 인터넷 | 통신사들 |

## 네트워크 장비 요약

| 장비 | 계층 | 역할 | 예시 |
|------|------|------|------|
| **NIC** | Physical/Data Link | 네트워크 연결 | 랜카드 |
| **Hub** | Physical | 신호 반복 (구식) | - |
| **Switch** | Data Link | MAC 주소로 스위칭 | 사무실 스위치 |
| **Router** | Network | IP 주소로 라우팅 | 공유기 |
| **AP** | Data Link | 무선 연결 | Wi-Fi AP |
| **Firewall** | Network+ | 보안, 패킷 필터링 | 방화벽 |
| **Modem** | Physical | 신호 변환 | 인터넷 모뎀 |

## 핵심 개념

### 1. 범위에 따라 네트워크 선택

- 책상 위: PAN (블루투스)
- 한 건물: LAN (이더넷, Wi-Fi)
- 여러 건물: CAN (광케이블)
- 한 도시: MAN (전용선)
- 전 세계: WAN (인터넷)

### 2. 계층적 설계

좋은 네트워크는 **계층적**입니다:

```
[코어 계층] - 핵심 라우터/스위치, 고속 백본
    ↓
[분배 계층] - 층별/부서별 스위치, VLAN 라우팅
    ↓
[액세스 계층] - 책상 스위치, AP, 최종 사용자 연결
```

### 3. 보안은 처음부터

네트워크를 만들 때 **보안을 먼저** 생각하세요:

- 방화벽 설치
- VLAN으로 분리
- 강력한 암호
- 정기적인 업데이트
- 최소 권한 원칙

### 4. 성능과 비용의 균형

무조건 빠른 게 좋은 건 아닙니다:

- 집: 100-500Mbps면 충분
- 소규모 사무실: 1Gbps
- 중견 기업: 1-10Gbps
- 대기업: 10-100Gbps

필요 이상으로 빠른 걸 사면 돈 낭비입니다.

### 5. 확장성 고려

처음부터 확장을 생각하세요:

- 여유 포트 20-30% 확보
- 케이블은 한 등급 높게 (Cat6A)
- 소프트웨어로 관리 가능한 장비
- 모듈화된 설계

## 다음 단계

이제 네트워크의 유형과 장비를 알았습니다. 다음으로 배울 것은:

1. **OSI 7계층 모델**: 네트워크가 어떻게 작동하는지 깊이 이해
2. **TCP/IP 프로토콜**: 인터넷의 언어
3. **IP 주소 체계**: IPv4, IPv6, 서브넷팅
4. **라우팅과 스위칭**: 데이터가 목적지를 찾아가는 방법
5. **네트워크 보안**: 공격과 방어

## 실무 조언

### 네트워크 엔지니어가 되고 싶다면

1. **실습**: 집에 실습 랩을 만드세요. 중고 스위치/라우터는 저렴합니다.
2. **자격증**: CCNA (Cisco Certified Network Associate)를 공부하세요.
3. **커뮤니티**: 네트워크 엔지니어 커뮤니티에 가입하세요.
4. **최신 트렌드**: SDN, NFV, 클라우드 네트워킹을 배우세요.

### 일반 IT 종사자라면

1. **기본 이해**: 지금까지 배운 내용만으로도 충분합니다.
2. **문제 해결**: 네트워크 문제를 스스로 진단할 수 있습니다.
3. **의사소통**: 네트워크 팀과 효과적으로 소통할 수 있습니다.

### 일반 사용자라면

1. **집 네트워크**: 공유기 위치, Wi-Fi 설정을 최적화하세요.
2. **보안**: 강력한 암호, 정기적인 업데이트를 하세요.
3. **문제 해결**: 간단한 문제는 스스로 해결할 수 있습니다.

## 마지막 한마디

네트워크는 **보이지 않지만 우리 삶의 모든 곳에 있습니다**.

여러분이 지금 이 글을 읽는 것도 네트워크 덕분입니다. 넷플릭스를 보고, 카카오톡을 하고, 온라인 쇼핑을 하는 모든 것이 네트워크 없이는 불가능합니다.

네트워크를 이해하면:
- 문제를 빨리 해결할 수 있습니다
- 더 나은 의사결정을 할 수 있습니다
- 새로운 기술을 쉽게 배울 수 있습니다

**네트워크는 어렵지 않습니다. 단지 익숙하지 않을 뿐입니다.**

계속 공부하고, 실습하고, 질문하세요. 그러면 어느새 네트워크 전문가가 되어 있을 겁니다.
