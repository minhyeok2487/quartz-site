# AS 번호(Autonomous System Number)란?

AS 번호는 **자율 시스템 번호**를 의미합니다.

## 자율 시스템(AS)이란?
**자율 시스템**은 하나의 관리 주체(예: 회사, 통신사, 대학 등)가 운영하는 네트워크들의 집합입니다. 쉽게 말해서 "같은 조직이 관리하는 라우터들의 그룹"이라고 생각하면 됩니다.

예를 들어:
- KT의 네트워크 전체 → 하나의 AS
- SKT의 네트워크 전체 → 또 다른 AS
- 삼성전자의 내부 네트워크 → 또 다른 AS

## AS 번호가 필요한 이유는?
인터넷은 수많은 조직들이 각자의 네트워크를 운영하고 있습니다. 이런 서로 다른 네트워크들이 통신하려면 "너는 어느 조직 네트워크니?"를 구분할 방법이 필요한데, 그게 바로 **AS 번호**입니다.

## IGRP에서 AS 번호의 역할
IGRP에서 AS 번호는 **같은 그룹임을 식별하는 용도**로 사용됩니다.

```bash
router igrp 100
```

여기서 100이 바로 AS 번호입니다.

**중요한 점:**
- 같은 AS 번호를 가진 라우터들끼리만 라우팅 정보를 교환합니다
- AS 번호가 다르면 같은 IGRP를 사용해도 서로 통신하지 않습니다
- 하나의 회사 내부에서는 같은 AS 번호를 사용해야 합니다

RIP는 AS 번호가 필요 없지만(`router rip`), IGRP는 반드시 AS 번호를 지정해야 합니다(`router igrp 100`). 이것이 두 프로토콜의 중요한 차이점 중 하나입니다!
