## 🎯 한 줄 요약
**케이블 TV 선으로 인터넷을 제공하는 통신사 쪽 핵심 장비**

## 💡 쉬운 비유

```
[당신 집 케이블 모뎀] ←─── 동축케이블 ───→ [통신사의 CMTS]
     (전화기)                                  (교환기)
```

- **케이블 모뎀** = 당신 집에 있는 인터넷 공유기 앞에 달린 장비
- **CMTS** = 통신사 설비실에 있는 "케이블 모뎀들의 상사" 역할

## 🔌 동작 원리
### 1. 집에서 인터넷 요청

```
당신: "유튜브 보고 싶어!" 
→ 케이블 모뎀: 신호를 RF(라디오 주파수)로 변환 
→ 동축 케이블(TV 선)로 전송
```

### 2. CMTS가 받아서 처리

```
CMTS: RF 신호 받음 
→ 디지털 데이터로 변환 
→ 인터넷 백본으로 전달
```

### 3. 응답도 반대로

```
인터넷 → CMTS → RF 신호 변환 → 케이블 → 당신 집 모뎀
```

---

## 🏢 실제 모습

**CMTS는 이런 일을 해요:**

- 수백~수천 개의 케이블 모뎀 관리
- 각 집마다 속도 제어 (100Mbps, 500Mbps 등)
- 누가 얼마나 쓰는지 모니터링
- IP 주소 할당 (DHCP)

---

## 📺 왜 케이블 TV 선으로?

|구분|설명|
|---|---|
|**역사**|원래 TV 방송용이었던 동축케이블을 재활용|
|**장점**|이미 깔려있어서 추가 공사 불필요|
|**기술**|DOCSIS 프로토콜로 TV + 인터넷 동시 전송|

---

## 🎬 당신이 본 프로젝트와의 관계

**CMB 프로젝트 = CMTS 장비 교체**

```
구형 CMTS (모토로라)          신형 CMTS (시스코)
    ↓                             ↓
 64QAM (느림)      →→→         256QAM (빠름)
 1.6MHz (좁음)    →→→          3.2MHz (넓음)
```

**결과:** 같은 케이블로 **4배 빠른 인터넷** 가능! 🚀

## 🤔 왜 중요해?

- **통신사 입장:** 이게 고장나면 해당 지역 전체 인터넷 마비
- **가입자 입장:** 집 인터넷 속도와 안정성을 결정
- **당신 입장:** CCNA 공부할 때 나오는 네트워크 기술(OSPF, DHCP, QoS)이 **실제로 쓰이는 현장**

간단히 말하면, **케이블 인터넷의 심장**이에요! 💓
